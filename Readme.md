# martinjc.com

Personal website built with [Eleventy](https://www.11ty.dev/).

[![Netlify Status](https://api.netlify.com/api/v1/badges/9626b842-4de6-4171-bebd-a271d99b9021/deploy-status)](https://app.netlify.com/sites/condescending-lewin-c5afe9/deploys)

## Development

- **Start dev server** (with live reload and watch):
  ```bash
  npm start
  ```
- **Build for production**:
  ```bash
  npm run build
  ```
- **Process images only**:
  ```bash
  npm run build:images
  ```
